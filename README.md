## 📌 Overview

**PredictiveMotorAI** bridges the gap between embedded systems, IoT, and artificial intelligence.  
The repository offers ready‑to‑run firmware examples that demonstrate:

- 📡 **Bluetooth & BLE Communication** – real‑time device interaction and data transfer  
- 📊 **Sensor Integration** – accelerometers, gyroscopes, magnetometers, pressure sensors, microphones, etc.  
- 💾 **Data Logging** – efficient storage of sensor readings and motor performance metrics  
- 🌐 **Wireless Protocols** – WiFi and MQTT client implementations  
- 🧠 **AI & Predictive Control** – machine learning inference directly on STM32 microcontrollers  

Whether you’re exploring edge AI, advanced motor control, or IoT prototyping, this repo is a hands‑on guide to modern STM32 development.

## 📁 Project Structure

| Folder / Project | Description |
|-----------------|-------------|
| `BLEDefaultFw`, `BLEMLC`, `Bluetooth` | Bluetooth Low Energy projects and machine learning core integration |
| `DATALOG2-STWIN.box`, `SDDataLogFileX` | High‑speed sensor data acquisition and SD‑card logging |
| `IIS2DLPC`, `ISM330DHCX` | MEMS accelerometer & gyroscope drivers and examples |
| `Nx_MQTT_Client`, `Wifi_MQTT` | Wireless IoT connectivity over WiFi and MQTT |
| `Led`, `uart2` | Peripheral and serial communication basics |
| `SupcomAI`, `Projet_PFE` | Advanced predictive motor control with AI |
| *…and many more* | Additional ready‑to‑build STM32 projects |

All projects are self‑contained, documented, and can be imported directly into **STM32CubeIDE**.

## 🚀 Getting Started

### Prerequisites
- [STM32CubeIDE](https://www.st.com/en/development-tools/stm32cubeide.html) (or your preferred STM32 toolchain)
- STM32CubeProgrammer (optional, for flashing via USB)
- A supported STM32 board (e.g., NUCLEO‑F401RE, STWIN, SensorTile)

### Installation

1. **Clone the repository**
   ```bash
   git clone https://github.com/Mejri-Mehdi/PredictiveMotorAI.git

2. **Open a project**

Launch STM32CubeIDE

File → Import → Existing Projects into Workspace

Select the desired project folder

3. **Build & Run**

Build the project (Project → Build All)

Flash the firmware to your board and start experimenting
